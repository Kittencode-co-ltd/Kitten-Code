คู่มือปฏิบัติงาน

วิธีใช้ระบบหลังบ้าน KITTEN CODE Co.,Ltd (บริษัท คิทเท่น โค้ด จำกัด)

เริ่มต้นใช้งาน
  1. เข้าที่หน้าเข้าสู่ระบบ กรอก ชื่อผู้ใช้ และรหัสผ่านที่แอดมินให้ แล้วกด "เข้าสู่ระบบ"
  2. ระบบพาไปหน้า "วันนี้" ซึ่งรวมงานของคุณ ประกาศล่าสุด และปุ่มลัดไว้ที่เดียว
  3. กดชื่อของคุณมุมขวาบน เพื่อสลับ ธีมสว่าง/มืด ภาษา ขนาดตัวอักษร ดูโปรไฟล์ หรือออกจากระบบ

ถ้าลืมรหัสผ่าน แจ้งแอดมินให้ตั้งรหัสใหม่ให้

เข้างาน - ออกงาน ทุกวัน
  1. เปิดเมนู เข้างาน / ลางาน แล้วกดปุ่มใหญ่ "เข้างาน" ตอนเริ่มทำงาน
  2. ตอนเลิกงานกด "ออกงาน" ปุ่มเดียวกัน
  3. เข้างานหลัง 09:15 ระบบจะนับว่า "สาย" ดูสรุปเดือนนี้ได้ที่แท็บ "เวลาทำงานของฉัน"

ลืมกดออกงาน? ภายในวันเดียวกันกดปุ่ม "แก้เวลาออกงาน" ได้ ถ้าข้ามวันแล้วให้แจ้งผู้บริหาร

ขอลางาน
  1. ไปที่ เข้างาน / ลางาน แล้วเลือกแท็บ "ลางาน"
  2. เลือกประเภท (ลาป่วย / พักร้อน / กิจ / อื่นๆ) วันที่เริ่ม-สิ้นสุด และเหตุผล แล้วกด "ส่งใบลา"
  3. รอผู้บริหารอนุมัติ สถานะขึ้นที่ "ใบลาของฉัน" ใบที่ยังรออนุมัติกด "ยกเลิก" ได้

ลาป่วยควรส่งใบลาในวันที่ลาหรือเร็วที่สุด

รับงานและอัปเดตงานในปฏิทิน
  1. งานที่ได้รับมอบหมายขึ้นที่หน้า "วันนี้" ในการ์ด งานของฉัน งานเลยกำหนดเป็นสีแดง
  2. กด เริ่มทำ เมื่อลงมือ และ ทำเสร็จ เมื่อส่งงาน (กดครั้งเดียว)
  3. ต้องการเพิ่มงานเอง ไปที่ "ปฏิทินและงาน" กด "เพิ่มงาน" ใส่ชื่องาน วัน ผู้รับผิดชอบ และโปรเจกต์

ใช้ตัวกรอง "ของฉัน" ในปฏิทินเพื่อดูเฉพาะงานตัวเอง

ยืม - คืนอุปกรณ์ส่วนกลาง
  1. เปิด อุปกรณ์ส่วนกลาง หาชิ้นที่ต้องการ (กิมบอล ไมค์ ฯลฯ) ที่สถานะ "ว่าง"
  2. กด "ยืม" เลือก กำหนดคืน และบอกว่าใช้ทำอะไร แล้วกดยืม
  3. เมื่อใช้เสร็จกด "คืนแล้ว" ที่ของชิ้นนั้น (ดูเร็วๆ ที่แท็บ "ที่ฉันยืมอยู่")

ของชำรุดหรือแบตหมดให้แจ้งแอดมินตอนคืน เพื่อทำเรื่องซ่อม

ออกเอกสารขาย (เสนอราคา → แจ้งหนี้ → ใบเสร็จ)
  1. กดปุ่ม "สร้างเอกสาร" (เมนูซ้ายหรือแถบบน) แล้วเลือกชนิดเอกสาร
  2. กรอกข้อมูลลูกค้าและรายการ ดูตัวอย่าง A4 ได้ทันที (บนมือถือสลับ "กรอกข้อมูล/ดูตัวอย่าง")
  3. กด บันทึก เพื่อเก็บเข้าทะเบียน หรือ พิมพ์ เพื่อออก PDF
  4. ที่ "เอกสารทั้งหมด" กด "ออกใบแจ้งหนี้" จากใบเสนอราคา และ "ออกใบเสร็จ" จากใบแจ้งหนี้ ข้อมูลถูกคัดลอกให้เอง

ต้องแก้เอกสารที่บันทึกแล้ว เปิดจากทะเบียนเอกสารแล้วกด "แก้ไข"

ขอซื้อ / ขอเบิก / ขอจ้าง
  1. สร้างเอกสาร → ใบเบิก / ซื้อ / จ้าง แล้วเลือกชนิด: ใบขอซื้อ (PR), ใบสั่งซื้อ/จ้าง (PO), ใบขอเบิก, หรือใบสำคัญจ่าย (PV)
  2. กรอกรายการ ยอดเงิน และเหตุผล แล้วกดบันทึก
  3. รอผู้บริหารอนุมัติในทะเบียนเอกสาร เมื่ออนุมัติแล้วออกขั้นถัดไป (PR → PO → PV) ได้ด้วยปุ่ม "ออก…"

ไม่มีใบเสร็จ ให้ใช้ "คำรับรองแทนใบเสร็จ" ในใบสำคัญจ่าย

ออกหนังสือรับรอง / เกียรติบัตร
  1. กดเมนู ออกหนังสือรับรอง (หรือปุ่ม "สร้างเอกสาร" แล้วเลือกชนิดตรง ๆ) จะเจอหน้าเลือกชนิดเอกสารเป็นการ์ดใหญ่
  2. เลือกชนิด: รับรองการทำงาน, รับรองการฝึกงาน, หรือเกียรติบัตร/ประกาศนียบัตร 6 แบบ
  3. กรอกชื่อผู้รับ ตำแหน่ง ช่วงเวลา และผู้ลงนาม ดูตัวอย่าง A4 ได้ทันที
  4. กด บันทึกลงทะเบียนเอกสาร เพื่อเก็บเข้าระบบ หรือ ส่งออก PDF เพื่อพิมพ์

เลือกผิดชนิด กดปุ่ม "เปลี่ยนประเภท" ในแถบสีฟ้าด้านบนฟอร์ม ข้อมูลที่กรอกแล้วจะไม่หาย

ออกหนังสือติดต่อภายนอก
  1. สร้างเอกสาร → หนังสือติดต่อภายนอก เลือกประเภท (เชิญ ตอบรับ ขอความอนุเคราะห์ ฯลฯ)
  2. ตรวจชื่อบริษัท ที่อยู่ เลขที่หนังสือ แล้วบันทึก/พิมพ์เป็น PDF

ชื่อบริษัทบนหนังสือคือ "บริษัท คิทเท่น โค้ด จำกัด"

สร้าง QR Code
  1. เปิด QR Code เลือกชนิด (ลิงก์ เบอร์ พร้อมเพย์ Wi-Fi นามบัตร ฯลฯ)
  2. ปรับสี โลโก้ ข้อความใต้ภาพ แล้วดาวน์โหลดเป็น PNG หรือ SVG
อ่านประกาศ นโยบาย และวิสัยทัศน์
  1. เปิด ประกาศ / นโยบาย เพื่ออ่านวิสัยทัศน์ พันธกิจ ค่านิยมองค์กร และประกาศล่าสุด
  2. ประกาศที่ปักหมุดจะอยู่บนสุดและขึ้นที่หน้า "วันนี้" ด้วย
เริ่มวัน: ดูหน้า "วันนี้"
  1. การ์ด รอดำเนินการ บอกจำนวนใบเสนอราคา/ใบเบิกรออนุมัติ ใบแจ้งหนี้รอชำระ และรายการเบิกจ่ายรออนุมัติ
  2. กดแถวไหนก็ไปที่รายการนั้นได้เลย (เห็นรายการเบิกจ่ายเฉพาะแอดมิน)
  3. เปิด เข้างาน / ลางาน → ทีมวันนี้ เพื่อดูว่าใครเข้างาน ใครลา
อนุมัติใบลา
  1. เปิด เข้างาน / ลางาน แท็บ "ทีมวันนี้" จะมีการ์ด "ใบลารออนุมัติ" (มีตัวเลขแสดงที่แท็บ)
  2. ตรวจประเภท วันที่ จำนวนวัน และเหตุผล แล้วกด อนุมัติ หรือ ไม่อนุมัติ
  3. คนที่ลาที่อนุมัติแล้ว จะขึ้นป้าย "ลา" ในรายชื่อทีมของวันนั้น

ระบบนับวันลาตามปฏิทินติดกัน ยังไม่ตัดเสาร์-อาทิตย์/วันหยุด จึงควรดูวันที่ประกอบ

อนุมัติการเบิกจ่าย
  1. ทะเบียนเอกสาร: เปลี่ยนสถานะใบเสนอราคา/ใบเบิก/ใบแจ้งหนี้จากช่อง "สถานะ" ในแถวได้ทันที
  2. บัญชี → รายการเงิน: รายการที่ "รอ" จะมีปุ่มอนุมัติ/ไม่อนุมัติ เฉพาะแอดมิน
  3. อนุมัติใบเบิกแล้ว สั่ง "ออกใบสำคัญจ่าย" ต่อได้ เมื่อจ่ายเงินแล้วเปลี่ยนเป็น "จ่ายเงินแล้ว"

ใบเสร็จรับเงินลงบัญชีเป็นรายรับ และใบสำคัญจ่ายลงเป็นรายจ่าย ผ่านปุ่มบันทึกลงบัญชีในทะเบียนเอกสาร

ดูภาพรวมการเงิน
  1. ภาพรวม: กราฟรายรับ-รายจ่าย และงบประมาณแต่ละหมวด
  2. บัญชี → หมวดและงบประมาณ: ตั้งงบรายหมวดและรอบโควตา
  3. บัญชี → รายการเงิน: ค้นหา กรอง และตรวจรายการย้อนหลัง
จัดการผู้ใช้และสิทธิ์
  1. เปิด ผู้ใช้ → เพิ่มพนักงานใหม่ ใส่ชื่อผู้ใช้ อีเมล รหัสผ่านเริ่มต้น ตำแหน่ง
  2. ตั้งสิทธิ์ admin เฉพาะผู้บริหารที่ต้องอนุมัติและดูการเงินทั้งหมด พนักงานทั่วไปใช้ user
  3. พนักงานลาออก ให้ลบผู้ใช้ออก

อย่าตั้ง admin ให้คนจำนวนมาก เพราะ admin อนุมัติเงินและดูข้อมูลบุคคลได้

ดูแลอุปกรณ์ส่วนกลาง
  1. เพิ่มอุปกรณ์: กด "เพิ่มอุปกรณ์" ใส่ชื่อ รหัส หมวด
  2. อุปกรณ์เลยกำหนดคืนจะขึ้นสีแดง ตามคืนจากชื่อผู้ยืม
  3. "รับคืนแทน" ใช้เมื่อผู้ยืมลืมกดคืน "แจ้งซ่อม" จะไม่ให้ยืม และ "ซ่อมเสร็จ" เพื่อเปิดให้ยืมอีกครั้ง
ประกาศ นโยบาย วิสัยทัศน์ พันธกิจ
  1. ประกาศ / นโยบาย → แก้ไข (กรอบ "เกี่ยวกับ KITTEN CODE") เพื่อกรอกวิสัยทัศน์ พันธกิจ ค่านิยม (ค่านิยมเขียนบรรทัดละ 1 ข้อ)
  2. กด "เขียนประกาศ" เลือกประเภท ประกาศ หรือ นโยบาย เลือก "ปักหมุด" ถ้าต้องการให้ขึ้นบนสุดและหน้า "วันนี้"
  3. แก้หรือลบได้ภายหลังจากการ์ดประกาศ
ทำสัญญา (เฉพาะแอดมิน)
  1. กดเมนู ทำสัญญา หรือปุ่ม "สร้างเอกสาร" แล้วเลือกชนิดสัญญา: จ้างทำของ, จ้างทำของแบ่งรายได้ %, จ้างแรงงาน, รักษาความลับ (NDA), จ้างพัฒนาเว็บ/ซอฟต์แวร์
  2. กรอกข้อมูลคู่สัญญา ที่อยู่ เลขบัตร และเงื่อนไขงาน ข้อความตามกฎหมายจะถูกเติมให้เอง ดูตัวอย่างได้ทันที
  3. ดูกล่องเตือนด้านบนฟอร์ม เช่น งวดชำระรวมไม่เท่ากับค่าจ้าง หรือทดลองงานเกิน 119 วัน แล้วแก้ให้ครบ
  4. กด บันทึกลงทะเบียนเอกสาร แล้วพิมพ์ให้คู่สัญญาลงนามพร้อมพยาน 2 คน จากนั้นเปลี่ยนสถานะเป็น "ลงนามแล้ว" ที่แท็บ "สัญญา" ในเอกสารทั้งหมด

แม่แบบเป็นข้อความทั่วไป ควรให้ทนายความตรวจก่อนใช้กับสัญญามูลค่าสูงหรือกรณีพิเศษ

ข้อควรปฏิบัติของผู้บริหาร
  1. ตรวจใบลาและใบเบิกรออนุมัติอย่างน้อยวันละ 1 ครั้ง
  2. ไม่แชร์ชื่อผู้ใช้/รหัสผ่านร่วมกัน ให้ทุกคนมีบัญชีของตัวเอง
