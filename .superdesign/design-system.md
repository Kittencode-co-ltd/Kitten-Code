## Brand
- Logo: the supplied round badge (cat inside code brackets, white interior). Always use the exact Brand Asset logo — never initials, emoji or an invented mark.
- Brand colour: orange #FF4A17. Use it sparingly — primary button, one highlight word, small indicators. Never large orange floods.

## Typography
- Latin & numbers: "Inter" (400/500/600; display 600 with tracking -0.03em).
- Thai: "IBM Plex Sans Thai" (400/500/600), set as `font-family: "Inter", "IBM Plex Sans Thai", system-ui, sans-serif` so each script picks its font.
- Mono for codes/registration numbers only: "JetBrains Mono".
- Scale: display 64–88px desktop / 40px mobile, h2 40–48px, h3 20–24px, body 17px (Thai line-height 1.7), small 14px.

## Colour tokens
Light: bg #FFFFFF, subtle #F6F6F7, card #FFFFFF, border #E8E8EB, ink #0B0B0F, muted #5C5F6A, accent #FF4A17, accent-ink (text on white) #D63A0C, on-accent #0B0B0F.
Dark: bg #0A0C12 (deep navy-black, never pure #000), subtle #10131B, card #141824, border #232838, ink #F2F3F7, muted #9AA0AE, accent #FF5A28, on-accent #0A0C12.
Depth: hairline borders + soft layered shadows in light (0 1px 2px rgba(11,11,15,.05), 0 12px 32px -16px rgba(11,11,15,.18)); in dark use slightly lighter raised cards and a faint inner top highlight.

## Layout
- Max content width 1200px, 12-column grid, generous whitespace (sections 112–144px tall padding desktop).
- Radius: buttons 10px, cards 16px, images 12px.
- Header: logo + wordmark left, 5 links, language switch, theme toggle, "Email us" button. Sticky with blurred background on scroll.
- Icons: thin outline (1.5px), Lucide-style.

## Motion
- Subtle and purposeful: section content fades up 16px on scroll (600ms, cubic-bezier(.2,.7,.2,1)), image hover scale 1.03, link underline sweep, theme crossfade 400ms.
- No floating orbs, glowing blobs, particle fields, rotating rings, or decorative gradient meshes. Respect prefers-reduced-motion.

## Must avoid (reads as generic/AI-made)
- Purple/blue gradient washes, glassmorphism, neon glows, emoji icons, stock "AI brain" imagery, fake stats or testimonials, lorem ipsum, three identical icon cards in a row.
